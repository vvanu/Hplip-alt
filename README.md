# hplip-alt

Скрипт `hplip-alt-setup.sh` для ALT Linux 9: ставит HPLIP + CUPS из репозитория (`apt-get`),
запускает службу печати, находит подключённый принтер HP (USB/сеть) и настраивает его.
Во время работы показывает прогресс по шагам (полоса `[####---] 42%`) и бегущую полосу с таймером
на долгих операциях, чтобы было видно, что скрипт не завис.

```
su -                                   # войти под root
bash ./hplip-alt-setup.sh              # установка и настройка
bash ./hplip-alt-setup.sh --test       # + напечатать тестовую страницу
```

## Параметры

| Параметр | Что делает |
|---|---|
| `--plugin` | сразу поставить плагин HP |
| `--no-plugin` | не ставить плагин HP |
| `--plugin-dir DIR` | папка с заранее скачанным `hplip-<версия>-plugin.run` (+ `.run.asc`) |
| `--ip АДРЕС` | дополнительно настроить сетевой принтер по IP |
| `--default` | сделать принтер по умолчанию |
| `--test` | напечатать тестовую страницу без вопроса |
| `--no-gui` | не ставить `hplip-gui` |

Журнал работы: `/var/log/hplip-alt-setup.log`.

## Что делает скрипт

1. Установка: репозиторий (с автоподбором имён пакетов `hplip*`) → `apt-get -f` и повтор → сборка из исходников.
2. Перезагрузка правил udev (принтер доступен по USB без перезагрузки), запуск CUPS несколькими способами.
3. Поиск: hp-makeuri → lpinfo → hp-probe (USB/сеть) → бэкенды CUPS; до 4 попыток с перезапуском CUPS.
4. Плагин HP (если нужен модели; определяется по пометке `requires proprietary plugin` в PPD):
   версия плагина **должна точно совпадать** с версией HPLIP (`rpm -q hplip`). Скрипт ищет готовый файл
   на диске (рядом со скриптом, в `/root`, `/home`, `/tmp`, `--plugin-dir`), проверяет версию внутри файла,
   при отсутствии пытается скачать (openprinting.org, sourceforge) и ставит через `hp-plugin -i -p`.
5. Настройка: `hp-setup -i -a` → PPD по модели → foo2zjs/foomatic → IPP Everywhere → общий HP-драйвер → универсальный PCL/raw.
   Каждый способ пробуется и с альтернативными URI (usb/dnssd/ipp). Уже существующая очередь на этот принтер не дублируется.
6. Тестовая печать; если печать упала из-за плагина, плагин ставится и печать повторяется.

## Если плагин HP не скачивается (например, нет доступа к серверам HP из сети)

Нужен для моделей вроде LaserJet P1005/P1006/P1505/P1566. Без него печать падает с
`Print job failed - required plug-in not found`. Скачайте в браузере два файла для **вашей** версии HPLIP
(не переименовывая!), положите рядом со скриптом или в `/root` и запустите скрипт снова:

```
https://www.openprinting.org/download/printdriver/auxfiles/HP/plugins/hplip-<версия>-plugin.run
https://www.openprinting.org/download/printdriver/auxfiles/HP/plugins/hplip-<версия>-plugin.run.asc
(или https://sourceforge.net/projects/hplip/files/hplip/<версия>/)
```

Вручную: `hp-plugin -i -p /папка/с/файлами` (от root). Проверка: `ls /usr/share/hplip/data/firmware/ | grep -i <модель>`
и `cat /var/lib/hp/hplip.state` (должно быть `installed=1` и нужная версия).
