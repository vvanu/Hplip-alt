# hplip-alt: автонастройка принтера HP в ALT Linux 9

Скрипт `hplip-alt-setup.sh` сам устанавливает HPLIP и CUPS, находит подключённый принтер HP (USB или сеть)
и настраивает его. Если какой-то способ не сработал, пробует запасной. Во время работы показывает полосу
прогресса и бегущий индикатор с таймером, поэтому видно, что скрипт работает, а не завис.

Проверено на практике: **HP LaserJet Professional P1566** (USB, ALT Linux 9).

---

## Инструкция по пунктам

### Шаг 1. Подготовьте компьютер и принтер
1. Включите принтер и подключите его USB-кабелем к компьютеру (или подключите к сети).
2. Убедитесь, что на компьютере есть интернет (нужен для `apt-get`).

### Шаг 2. Скачайте скрипт
Выберите один из способов.

**Способ А. Через git** (если git не установлен: `su -`, затем `apt-get install git`):
```bash
git clone -b claude/alt-linux-hplip-printer-setup-1rjfts https://github.com/vvanu/hplip-alt.git
cd hplip-alt
```

**Способ Б. Одним файлом через wget:**
```bash
wget -O hplip-alt-setup.sh https://raw.githubusercontent.com/vvanu/hplip-alt/claude/alt-linux-hplip-printer-setup-1rjfts/hplip-alt-setup.sh
```

**Способ В. Через браузер:** откройте страницу репозитория, нажмите **Code → Download ZIP**, распакуйте архив.

### Шаг 3. Станьте root
В ALT Linux `sudo` по умолчанию не настроен, поэтому:
```bash
su -
cd /путь/к/папке/со/скриптом
```
(`cd hplip-alt`, если клонировали в домашнюю папку root; для обычного пользователя папка лежит в `/home/имя/hplip-alt`.)

### Шаг 4. Запустите скрипт
```bash
bash ./hplip-alt-setup.sh --test
```
Ключ `--test` в конце сам напечатает тестовую страницу. Без ключа скрипт спросит об этом.

### Шаг 5. Дождитесь окончания
Скрипт идёт по 7 шагам, на экране видна полоса прогресса и таймер:

| Шаг | Что происходит |
|---|---|
| 1 | Обновление списков пакетов |
| 2 | Установка CUPS и HPLIP |
| 3 | Запуск службы печати |
| 4 | Поиск принтера (до 4 попыток) |
| 5 | Плагин HP (если модели нужен) и настройка принтера |
| 6 | Проверка, принтер по умолчанию |
| 7 | Тестовая печать |

Если на долгой операции бегущая полоса и таймер идут, всё в порядке, просто ждите (установка пакетов и
плагина может занять несколько минут).

### Шаг 6. Если нужен плагин HP, а он не скачивается
Некоторым моделям (LaserJet P1005/P1006/P1505/P1566 и др.) нужен проприетарный плагин HP. Скрипт сам определяет
это и пытается скачать плагин. Если сеть не пускает на серверы HP, скрипт выведет ссылки. Тогда:

1. Узнайте версию HPLIP: `rpm -q hplip` (например, `hplip-3.21.10-...` значит версия **3.21.10**).
2. В браузере скачайте **два файла этой же версии** (не переименовывая):
   - `https://www.openprinting.org/download/printdriver/auxfiles/HP/plugins/hplip-<версия>-plugin.run`
   - `https://www.openprinting.org/download/printdriver/auxfiles/HP/plugins/hplip-<версия>-plugin.run.asc`
   - либо из папки `https://sourceforge.net/projects/hplip/files/hplip/<версия>/`
3. Положите файлы рядом со скриптом, в `/root` или в `/home/<имя>` и запустите скрипт снова. Он сам найдёт файлы,
   проверит версию внутри и установит плагин. Папку можно указать явно: `--plugin-dir /путь/к/папке`.

> Версия плагина должна **точно совпадать** с версией HPLIP, иначе установка завершится ошибкой
> `Plug-in version mismatch`.

### Шаг 7. Проверьте печать
Напечатайте любой документ или выполните:
```bash
lp -d HP_LaserJet_Professional_P1566 /usr/share/cups/data/testprint
lpstat -t        # состояние очередей
```
(Имя очереди скрипт показывает в конце работы и в `lpstat -t`.)

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| `Принтер не найден` | Проверьте кабель и питание принтера, запустите скрипт снова. Для сетевого принтера: `--ip АДРЕС`. |
| Ошибка печати `required plug-in not found` | Нужен плагин HP, см. шаг 6. |
| `Plug-in version mismatch` | Версия плагина не совпадает с версией HPLIP (`rpm -q hplip`), скачайте файл нужной версии. |
| `Отказано в доступе` при установке плагина | Скрипт и `hp-plugin` нужно запускать от root (`su -`). |
| Шаг идёт очень долго | Если бегущая полоса и таймер идут, ждите. Подробности: `tail -f /var/log/hplip-alt-setup.log`. |
| Две очереди на один принтер | Лишнюю можно удалить: `lpadmin -x ИМЯ_ОЧЕРЕДИ`. |
| В очереди зависли старые задания | `cancel -a`, затем `cupsenable ИМЯ_ОЧЕРЕДИ`. |
| Ничего не помогло | Пришлите `tail -50 /var/log/hplip-alt-setup.log` и `lpstat -t`. |

## Параметры

| Параметр | Что делает |
|---|---|
| `--test` | напечатать тестовую страницу без вопроса |
| `--plugin` | сразу поставить плагин HP |
| `--no-plugin` | не ставить плагин HP |
| `--plugin-dir DIR` | папка с заранее скачанным `hplip-<версия>-plugin.run` (+ `.run.asc`) |
| `--ip АДРЕС` | дополнительно настроить сетевой принтер по IP |
| `--default` | сделать принтер по умолчанию |
| `--no-gui` | не ставить `hplip-gui` |

Журнал работы: `/var/log/hplip-alt-setup.log`.

## Как скрипт подбирает способ настройки

1. **Установка:** репозиторий (с автоподбором имён пакетов `hplip*`) → `apt-get -f` и повтор → сборка из исходников.
2. **Поиск принтера:** `hp-makeuri` → `lpinfo` → `hp-probe` (USB и сеть) → бэкенды CUPS (usb/dnssd/ipp).
3. **Плагин HP:** определяется по пометке `requires proprietary plugin` в PPD; версия сверяется с HPLIP; файл ищется на диске,
   затем скачивается (openprinting.org, sourceforge); установка через `hp-plugin -i -p`.
4. **Настройка очереди:** `hp-setup -i -a` → PPD по модели → `foo2zjs`/`foomatic` → IPP Everywhere → общий HP-драйвер →
   универсальный PCL/raw. Каждый способ пробуется и с альтернативными адресами устройства. Уже существующая очередь
   на тот же принтер не дублируется.
5. **Тестовая печать:** если печать не прошла из-за плагина, плагин ставится и печать повторяется.
